# ESP32-S3 + MAX30102: исправление baseline

Откройте `HRV_ESP32_Dissertation.ino` из этой папки в Arduino IDE. Переносите всю папку, включая `src/max3010x`: в неё включён используемый драйвер SparkFun 1.1.2 с двумя исправлениями предупреждений компилятора. Глобальная библиотека не заменяется.

Параметры сборки, использованные при проверке:

- ESP32 Core 3.3.10, плата ESP32S3 Dev Module.
- FQBN: `esp32:esp32:esp32s3:CDCOnBoot=cdc,UploadSpeed=115200`.
- USB CDC On Boot: Enabled; Serial Monitor: 115200.

Аппаратные настройки сохранены: SDA 8, SCL 9, 0x57, стандартная скорость I2C, 400 conversions/s, averaging 4, RED 0x1F, IR 0x2F, pulse width 411, ADC range 8192. Собственный PulseDetector и аппаратный FIFO reader сохранены.

Протокол: палец → 5 секунд стабильного контакта → 9 согласованных RR → отдельное 60-секундное окно → COMPLETE. Первые 3 кандидата отмечаются CANDIDATE; после взаимной проверки получают ACCEPTED. Пределы RR: 400–1500 мс включительно; согласованность baseline: ±20% медианы. Проверяется также медиана всего набора после добавления.

Провал IR на 2499 мс сохраняет baseline. Подтверждённый низкий IR в течение 2500 мс завершает текущую сессию; следующий контакт начинает протокол заново. Во время MEASURING потеря контакта или данных на 2500 мс отменяет измерение. COMPLETE сохраняет результат до снятия пальца.

RR считаются в sample clock; границы измерения и CSV — в wall clock. Окно определяется временем обработки FIFO, а не синхронизированными физическими метками оптического события. Это сохраняет задержку FIFO и номинальную точность частоты сенсора как ограничения прототипа.

Полный отчёт, diff и результаты тестов находятся уровнем выше. Тест на синтетическом сигнале не заменяет следующий тест на вашей плате. LOW_HRV / MODERATE_HRV / HIGH_HRV — исследовательские категории PRV; LOW_HRV не означает стресс.

## Веб-приложение React + Firebase

MVP расположен в `web/`: обзор, история с графиками, устройства, настройки. Запуск: `cd web`, `npm install`, `npm run dev`. Работает демо без конфигурации, реальные данные читаются из существующего `hrv_measurements` через Firebase Realtime Database. Настройка авторизации, закрытые правила доступа и инструкция адаптации ESP32: [web/README.md](web/README.md).

Перед сборкой Firebase-скетча скопируйте `secrets.example.h` в `secrets.h` рядом со скетчем и заполните локальные настройки. `secrets.h` и `web/.env` не публикуются. В рабочей папке существующие настройки сохранены в этих локальных файлах.
